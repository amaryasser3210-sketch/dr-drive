# amr_simulation

**Owner:** Robot modeling and simulation. Gazebo worlds and simulation launch.

## Contents
- `worlds/straight_lane.world` — Task 1: single lane, 0.40 m × 10 m black tape
- `worlds/two_lane.world` — Task 2: two lanes + obstacles at 4 m (right) and 8 m (left)
- `launch/` — spawn robot, load world, start sensor bridges

Geometry is defined in `config/lane_geometry.yaml` (SSOT). Keep worlds consistent with it.
